# 📖 Livro de Receitas Cooperativo

Este projeto é um repositório compartilhado criado para armazenar, organizar e documentar nossas receitas culinárias favoritas. O desenvolvimento é feito de forma totalmente colaborativa usando Git e GitHub.

* [Outras Receitas](receitas.txt)

##🤝 Como contribuir
1. Atualize seu repositório local antes de começar: `git pull origin main`
2. Crie uma nova branch para a sua receita: `git checkout -b minha-nova-receita`
3. Adicione ou modifique os arquivos de receita.
4. Salve suas alterações localmente: `git commit -m "Sua mensagem"`
5. Envie para o GitHub: `git push origin minha-nova-receita`
6. Abra um **Pull Request** para que a equipe revise suas alterações.
